Set up the [name]

  1. Download OwnYourNiimbot for your computer and install it.
  2. Turn on the printer. Close the NIIMBOT phone app first, because the printer accepts one connection at a time.
  3. Click Connect printer at the top of the window, click Bluetooth and select the printer. Its Bluetooth name starts with the model name. You do not need to pair it in the system settings.
  4. Click Templates, or click Labels and New label. The template list shows the sizes that fit the [name] and the loaded roll.
  5. Click Print, check the preview, set the copies and the density, and click Print again.

The Connect a printer and Design and print a label pages in the wiki have more detail.

Print area

On some rolls the print head is narrower than the label. The editor shades the parts of the label that do not print. If an element goes outside the print area, click Fit into the print area in the right panel to move and shrink the design. See Print area.

Report a print result

If the [name] does not print correctly, open an issue on GitHub with the model name, the firmware version from the Printer page and the communication log from the same page.
