--- title: Text, dates and serial numbers description: Add text to a NIIMBOT label in OwnYourNiimbot, choose a font, and add dates, best-before dates and serial numbers that change on each label. section: Design labels order: 2 ---

Text, Date and Serial elements all put text on the label. A Date element shows the date when the label prints. A Serial element counts up on each label.

Text

Click Text in the Insert panel. Double-click the text on the label to edit it there, or change it in the Text box on the right.

SettingDescription
FontA font that is included with the app, or a font on this computer
SizeThe text size
Line spacingThe space between lines
StyleBold, italic, underline and strikethrough
AlignmentLeft, centre, right or justify
Letter spacingThe space between letters
White text on blackPrints the text white on a black background
Insert a data fieldAdds a spreadsheet column or a built-in value. See Data fields

Included fonts

The app includes 19 fonts, so a label looks the same on every computer: Inter, Montserrat, Oswald, Bebas Neue, Archivo Black, Playfair Display, Abril Fatface, Cinzel, Roboto Slab, Pacifico, Great Vibes, Dancing Script, Caveat, Permanent Marker, Amatic SC, Fredoka, Righteous, Space Mono and JetBrains Mono.

The font list also shows the fonts on this computer. A label with a system font looks different on a computer that does not have that font.

Thermal printers print in black only. Small text prints more clearly in a bold, simple font such as Inter or Montserrat. Check small text in the print preview, which shows the label at the printer resolution.

Dates and times

Click Date in the Insert panel. The element shows the date and time when the label prints.

  • Date format: DD/MM/YYYY, D MMM YYYY, YYYY-MM-DD, MM/DD/YYYY, DD.MM.YYYY, ddd D MMM, HH:mm, DD/MM/YYYY HH:mm or YYYY-MM-DD HH:mm:ss.
  • Add days: adds a number of days to the date. Use it for best-before, use-by or expiry dates. For example, 3 days on 22 November prints 25 November.

The format letters are listed on the Data fields page.

Serial numbers

Click Serial in the Insert panel. The number goes up on each label of a print job.

SettingDescription
PrefixText before the number, for example A-
SuffixText after the number
StartThe number on the first label
StepThe amount added for each label
DigitsThe minimum number of digits. The app adds leading zeros, for example 0007. From 1 to 12

The panel shows an example of the first three numbers, for example "A-0001, A-0002, A-0003".

In the print dialog, Number of serial labels sets how many numbered labels to print. To put the label number in a text or a barcode, use the {{index}} field. See Data fields.
