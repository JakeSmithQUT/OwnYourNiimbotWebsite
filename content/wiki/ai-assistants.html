--- title: AI assistants (MCP) description: Let Claude Code, Claude Desktop or another MCP client make, preview and print NIIMBOT labels through the local OwnYourNiimbot MCP server. section: App and settings order: 4 ---

An AI assistant on the same computer can make labels, look at a preview and print through the Model Context Protocol (MCP). The server is off by default. It accepts connections from this computer only and needs a token.

Turn on the server

  1. Go to Settings, AI assistants (MCP).
  2. Select Allow AI assistants to use OwnYourNiimbot. The section shows "Running on port 47821", the address and the token.
  3. Copy the setup for your assistant from the same section.

Claude Code

Copy the Claude Code command and run it once in a terminal: PowerShell, Command Prompt, or Terminal on macOS and Linux. Then start a new Claude Code session.

Claude Desktop

Copy the JSON from Claude Desktop (claude_desktop_config.json), add it to claude_desktop_config.json, then restart Claude Desktop. Claude Desktop starts a small bridge program that comes with the app, so it needs the installed app. The portable Windows version runs from a temporary folder and does not work with Claude Desktop.

Other MCP clients

Use the address http://127.0.0.1:47821/mcp with the header Authorization: Bearer <token>. If port 47821 is in use, the app tries the next nine ports, and the section shows the port that it uses.

Assistant tools

ToolAction
get_statusShows the connected printer, the loaded roll, the open label, the included fonts and the barcode types
list_label_sizesLists the NIIMBOT rolls that fit the printer
list_templatesSearches the template library
create_labelMakes a label from text, codes and other elements
create_from_templateMakes a label from a template at one of its sizes, with the sample text replaced
edit_label_textMakes a copy of a label with text replaced
preview_labelReturns an image of the label as the printer prints it, with the parts outside the print area in grey
list_saved_labelsLists your saved labels
save_labelSaves a label to your labels
print_labelPrints a label

Example request: "Make a label for each of switch ports 1 to 8 on the loaded roll and show me a preview."

Print approval

Ask me before an assistant prints is on by default. Before each print job from an assistant, the app shows the label name, the size, the number of labels and the printer, and waits for you to click Print.

Token

The token is stored in the app data folder. Click Make a new token if you think that someone else has it, then update the token in your assistant.

Reconnect after an update

Reconnect the assistant after the app updates. In Claude Code, run /mcp.
