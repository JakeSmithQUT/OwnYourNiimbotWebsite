Shapes and lines make borders, boxes and dividers. A table puts text in rows and columns, for example for a parts list or a set of specifications.

Shapes

Click Rectangle, Rounded or Circle in the Insert panel.

  • Line width: the thickness of the outline, from 0.1 to 10 mm.
  • Fill black: fills the shape. Put white text on top of a filled shape for a heading bar, or use White text on black on the text element.
  • Dashed line: draws the outline with dashes.
  • Corner radius: the size of the rounded corners of a rectangle. A rounded rectangle starts with a corner radius. A circle does not have this setting.

Lines

Click Line for a horizontal line or Vertical for a vertical line. Set the Line width, and select Dashed line for a cut or fold mark.

Tables

Click Table in the Insert panel. In the right panel:

  • Rows and Columns: the number of cells.
  • Cells: the text in each cell. A new table has the text "Item 1", "Item 2" and so on.
  • Font, Text size, Line width and Bold apply to the whole table.

Cells can hold data fields, for example {{Serial}}. See Data fields.

Change the type of an element

Right-click an element and point to Replace with to change it to a different type in the same place, for example a rectangle to a rounded rectangle, or a line to a vertical line.
