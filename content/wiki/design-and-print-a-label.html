--- title: Design and print a label description: Make a first label in OwnYourNiimbot: create a new label or open a template, add text and a barcode, check the preview and print. section: Install and set up order: 5 ---

This page takes you from an empty label to a printed one. Connect the printer first, so that the app knows the model and the loaded roll.

Start a label

Use one of these:

  • On the Labels page, click New label. The dialog selects the roll in the printer. Select a different NIIMBOT roll, or enter the width and height, then click Create.
  • On the Templates page, find a design and click one of its sizes. See Template library.
{%figure design | The design view with an asset tag label. The Insert panel is on the left and the label settings are on the right.%}

Add and change elements

  1. Click a tool in the Insert panel on the left, for example Text or Barcode. The new element is added to the label and selected.
  2. Change the element in the panel on the right: the text, the font, the size, the barcode content.
  3. Drag the element to move it. Drag a corner handle to resize it. Double-click a text element to edit the text on the label.

Right-click an element for more actions: replace it with a different type, duplicate it, move it to the front or back, lock it or delete it.

Check the print area

If the print head is narrower than the label, the editor shades the parts that do not print. If an element goes outside the print area, the right panel shows a warning. Click Fit into the print area to move and shrink the design. See Print area.

Print

  1. Click Print at the top right, or press Ctrl + P.
  2. Check the preview. It shows the label at the printer resolution, as the printer receives it.
  3. Set Copies of each label and the print density.
  4. Click Print. The dialog shows the progress for each label.

Save the label

Press Ctrl + S or click Save. The label is saved on the Labels page. To keep a saved label and make a new one from it, change the name at the top of the window and save. See Saved labels and label files.

On macOS, use Cmd in place of Ctrl.
