--- title: Install on macOS description: Install OwnYourNiimbot on a Mac with Apple silicon or an Intel processor, open an app that is not code signed, and allow Bluetooth access. section: Install and set up order: 2 ---

OwnYourNiimbot has a disk image for Macs with Apple silicon (M-series chips) and one for Macs with an Intel processor.

Install the app

  1. Download the disk image for your Mac: Apple silicon ({%size macos-arm64%}) or Intel ({%size macos-x64%}). To find the chip, open the Apple menu and click About This Mac.
  2. Open the disk image and drag OwnYourNiimbot to the Applications folder.
  3. In Applications, right-click OwnYourNiimbot and click Open, then click Open in the message.
  4. When the app asks for Bluetooth access, click Allow. The app needs it to find the printer.

Open the app the first time

The app is not signed with an Apple developer certificate, so macOS blocks it the first time.

  • On macOS 15 and later, the right-click Open step can show the message again. Open System Settings, Privacy & Security, scroll to the message about OwnYourNiimbot and click Open Anyway.
  • If macOS says that the app is damaged and cannot be opened, remove the quarantine flag in Terminal, then open the app again:
xattr -dr com.apple.quarantine /Applications/OwnYourNiimbot.app

Download the app only from this site or from the GitHub releases page. To check the file, compare its checksum with the value on the download page:

shasum -a 256 ~/Downloads/{%file macos-arm64%}

Bluetooth access

If you clicked Don't Allow, the app cannot find printers. Open System Settings, Privacy & Security, Bluetooth, and turn on OwnYourNiimbot. Then restart the app.

Updates

On macOS the app checks for a new version when it starts and every 6 hours. When a new version is available, a bar links to the release page. Download the new disk image and replace the app in Applications. See Updates.

Remove the app

Drag OwnYourNiimbot from Applications to the Bin. Labels and settings are in ~/Library/Application Support/OwnYourNiimbot. Delete that folder too if you do not want to keep them.
