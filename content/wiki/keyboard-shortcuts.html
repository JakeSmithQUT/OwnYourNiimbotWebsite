--- title: Keyboard shortcuts description: Keyboard and mouse shortcuts in OwnYourNiimbot for saving, printing, undo, copy and paste, duplicating, selecting, moving and zooming. section: Reference order: 1 ---

On macOS, use Cmd in place of Ctrl. The design view shortcuts work when the cursor is not in a text box.

Labels

ShortcutAction
Ctrl + SSave the label
Ctrl + POpen the print dialog

Design view

ShortcutAction
Ctrl + ZUndo
Ctrl + Y or Ctrl + Shift + ZRedo
Ctrl + CCopy the selected elements
Ctrl + VPaste
Ctrl + DDuplicate the selected elements
Ctrl + ASelect all elements
Del or BackspaceDelete the selected elements
Arrow keysMove the selected elements by 0.5 mm
Shift + arrow keysMove the selected elements by 5 mm

Mouse

ActionResult
Ctrl + scroll wheelZoom in or out
Double-click a text elementEdit the text on the label
Right-click an elementOpen the element menu: replace, duplicate, front, back, lock and delete
Shift + clickAdd an element to the selection
Drag on an empty part of the labelSelect the elements in the area
