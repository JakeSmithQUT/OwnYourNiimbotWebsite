--- title: Label size detection description: How OwnYourNiimbot finds the size of the NIIMBOT roll in the printer, and how to save the size of a roll that it does not know. section: Printing order: 2 ---

When a printer connects, and when you close the cover after you change the roll, the app finds the size of the loaded roll. A new, empty label changes to that size.

Label size sources

The app tries these sources in order:

  1. Read from the printer: newer printer firmware reports the label size.
  2. Saved for this roll: a size that you saved for the barcode of the roll.
  3. From the label list: the list of NIIMBOT rolls in the app, matched by the roll barcode.

Genuine NIIMBOT rolls have an RFID tag with the roll barcode, the serial number and the number of labels. The app reads the tag through the printer.

Save the size of an unknown roll

If the app cannot find the size, the right panel of the design view shows "The loaded roll has no known size".

  1. Select the size in the NIIMBOT roll list, or enter the width and height.
  2. Click Save W × H mm for this roll.

The app uses the saved size each time it detects that roll.

A label with a different size

If you open a label with a different size from the roll in the printer, a banner above the label shows both sizes. Click Use W × H mm to change the label to the roll size, or Keep this size.

Turn off the automatic size

Clear Settings, Give a new, empty label the size of the roll in the printer.

Roll details on the Printer page

The Printer page shows the roll size and where it came from, the barcode, the roll serial, the labels on the roll, the labels used and the labels left. Detect the roll again reads the roll again. Forget the saved size deletes a size that you saved for the roll. See Printer page.
