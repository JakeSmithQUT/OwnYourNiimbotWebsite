--- title: Updates description: How OwnYourNiimbot checks GitHub for new versions, installs updates on Windows and Linux, and shows a link on macOS. How to turn the check off. section: App and settings order: 3 ---

The installed app checks the GitHub releases of the project when it starts and every 6 hours while it is open. The latest version is {%version%}, released {%date%}.

Windows installer and Linux AppImage

These versions install updates themselves.

  • When the app starts and an update is available, a small window shows the download. The installer then shows its progress, and the app opens again with a What's new link.
  • Click Start without updating to use the app while the update downloads. When it is ready, a Restart to update button shows at the top of the window.
  • If the open label has changes that are not saved, the app offers Save and restart.

The app checks the download before it installs it.

macOS, Windows portable and the .deb package

These versions cannot install updates themselves. When a new version is available, a bar shows a link to the release page. Download the new version from the download page and install it over the old one.

Turn off the update check

Go to Settings, Updates, and clear Check for updates automatically. Click Check now to check by hand.

Data that the check sends

The app asks GitHub for the latest release. GitHub gets the app version and the IP address of the computer. The app sends no labels or other data.

Reconnect AI assistants after an update

If you use the MCP server, reconnect the assistant after an update. In Claude Code, run /mcp.
