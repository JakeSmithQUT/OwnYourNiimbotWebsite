OwnYourNiimbot makes 12 types of barcode and 4 types of 2D code. A barcode or code can hold fixed text, a spreadsheet column or a number that changes on each label.

Add a barcode

  1. Click Barcode or QR code in the Insert panel.
  2. In the right panel, select the Type.
  3. Type the value in Content.
  4. Drag a corner of the code to resize it.

If the value is not valid for the type, the code shows "Invalid value". For example, EAN-13 accepts digits only.

Select Show text under the bars to print the value under the barcode, and set its Text size.

A QR code has an Error correction setting: L, M (default), Q or H. A higher level keeps the code readable when part of it is damaged, but makes the code denser.

Values from a spreadsheet

Select Insert a data field under Content to put a spreadsheet column in the code, for example {{Asset}}. Each label of a batch gets the value of its row. You can mix fields and text, for example https://example.com/asset/{{Asset}}. See Batch printing.

For numbers that count up, use {{index}} or {{index:6}}, which gives the label number with leading zeros, for example ORD-{{index:6}}. See Data fields.

Print size and scanning

  • The print preview shows the code at the printer resolution. Check that thin bars do not merge.
  • On a 12 mm or 15 mm roll, use a short value or a Data Matrix code.
  • Leave a blank margin around the code so that a scanner can find it.
  • If a scanner cannot read the code, make it larger or increase the print density.
