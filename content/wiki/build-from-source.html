--- title: Build from source description: Build OwnYourNiimbot from the source code with Node.js 22, run it in development mode, run the tests and build the installers. section: Reference order: 3 ---

The app is written in TypeScript with Electron, React, Vite and Fabric.js. You need Node.js 22 or later and Git.

Get the code and start the app

git clone https://github.com/JakeSmithQUT/OwnYourNiimbot.git
cd OwnYourNiimbot
npm install
npm run dev

npm run dev starts the app with live reload.

Commands

CommandResult
npm run devStarts the app with live reload
npm testRuns the tests, including full print jobs against a simulated printer
npm run typecheckChecks the TypeScript types
npm run buildBuilds the app into dist/
npm startOpens the built app
npm run dist:win, dist:mac, dist:linuxBuilds the installers into release/

Project layout

FolderContents
src/main/Electron main process: device pickers, permissions, file storage and updates
src/printer/Printer protocol, Bluetooth and serial connections, image encoding and the model table
src/renderer/React interface, label editor and template library
src/main/mcp/Local MCP server for AI assistants
tests/Vitest unit tests
