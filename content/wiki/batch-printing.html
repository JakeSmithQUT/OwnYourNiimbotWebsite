Print one label for each row of a spreadsheet, for example name badges, asset tags or server labels. The app reads .xlsx, .csv and .tsv files, and tables that you copy from Excel or Google Sheets.

{%figure data | The Data page with a table of names, departments, rooms and asset numbers, and a field button for each column.%}

Prepare the data

The first row holds the column names. Each other row is one label. For example, staff.csv:

NameRoomAsset
Ana Silva2.14A-1001
Ben Okafor2.16A-1002
Chloé Martin3.02A-1003

Load the data

  1. Click Data in the side bar.
  2. Click Open Excel or CSV file and select the file. Or copy the cells in Excel or Google Sheets and click Paste table.
  3. The page shows the rows and a field button for each column, for example {{Name}}. Click a field button to copy the field.

Use Filter rows to find rows. The page shows the first 1,000 rows, but the app prints all of them. Clear data removes the loaded data.

Put the fields on the label

  1. In the design view, select a text, barcode or QR code element.
  2. In the right panel, select a column in Insert a data field. The field shows as {{Name}}.
  3. Mix fields with normal text, for example Room {{Room}}. Put {{Asset}} in a barcode to encode the asset number.

Field names match the column names without regard to upper and lower case. See Data fields for the built-in fields such as the date and the label number.

Print the rows

  1. Click Print.
  2. Under Data rows, set From and To to the first and the last row to print.
  3. Use the arrows under the preview to step through the labels.
  4. Set Copies of each label if you need more than one of each, then click Print.

If the label has a field with no matching column, the print dialog shows "No data column for" and the field names.

Columns in a data file200

Example template

The Server labels from a spreadsheet template is a ready example with the columns Hostname, IP, BMC, Serial and Role. Open it from the Templates page. Its example data loads with it.

Tips

  • A serial number counts up across the batch, and a date can add a number of days.
  • Save the label after you load the data, so that the label opens with its data next time.
  • For a .xlsx file that is too large to open, save the sheet as CSV.
