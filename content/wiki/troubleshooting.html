--- title: Troubleshooting description: Fix common problems with OwnYourNiimbot and NIIMBOT printers: the printer is not found, Bluetooth errors, wrong label size, faint print, cut-off print and printer error messages. section: Reference order: 2 ---

Find the problem or the message, then do the steps. If the problem stays, open an issue on GitHub with the printer model, the firmware version and the communication log from the Printer page.

Install and start

Windows says "Windows protected your PC"

The app is not code signed. Click More info, then Run anyway. See Install on Windows.

macOS says that the app cannot be opened or is damaged

Right-click the app and click Open. On macOS 15 and later, use System Settings, Privacy & Security, Open Anyway. If macOS says that the app is damaged, run xattr -dr com.apple.quarantine /Applications/OwnYourNiimbot.app in Terminal. See Install on macOS.

The Linux AppImage does not start

Make the file executable with chmod +x. If it reports that FUSE is missing, install libfuse2 (libfuse2t64 on Ubuntu 24.04 and later). Start it from a terminal to see the error message, and add the message to an issue.

Connection

The printer is not in the Bluetooth list

  1. Make sure that the printer is on and charged.
  2. Close the NIIMBOT phone app, or turn off Bluetooth on the phone. The printer accepts one connection at a time.
  3. Click Show all Bluetooth devices in the connect dialog.
  4. Turn the printer off and on, then try again.

"Bluetooth is not available on this computer"

Turn on Bluetooth in the system settings. On macOS, give the app Bluetooth access in System Settings, Privacy & Security, Bluetooth. On Linux, Bluetooth needs BlueZ 5.41 or later.

"The printer service was not found"

The selected device is not a NIIMBOT printer, or it is a model with a different command set. Check the supported printers.

No serial ports show for a USB cable

Use a USB data cable. Some cables carry power only. On Linux, add your user to the dialout group (uucp on Arch) and log in again.

"The printer did not accept the data"

Disconnect the printer on the Printer page and connect it again. If the message comes back, turn the printer off and on.

Label size and position

The label size is wrong or unknown

Select the size in the NIIMBOT roll list or enter the width and height, then click Save W × H mm for this roll. See Label size detection.

Labels print in the wrong position or across two labels

  • Make sure that the Label type matches the roll: gap (die-cut), black mark or continuous.
  • On the Printer page, click Calibrate. The printer feeds a few labels to find the gap or the mark.
  • Check that the label size matches the roll. The print dialog shows a warning if it does not.

Part of the label does not print

The print head is narrower than the label. The editor shades the parts that do not print. Click Fit into the print area in the right panel. See Print area.

The print is upside down

Open Advanced in the print dialog and select Turn the print 180°, or select Turn every print 180° in Settings.

Print quality

The print is too light

  • Increase the print density in the print dialog.
  • Increase Settings, Black level to make grey and thin content print black.
  • Use a bolder font or thicker lines.

A photo prints as a black or grey area

Select the image and set Black and white to Dither (photos). Change the brightness and the contrast, and check the result in the print preview. See Images and photos.

A scanner cannot read the barcode

Make the barcode larger, leave a blank margin around it, and increase the print density. On narrow rolls, use a Data Matrix code. See Barcodes and 2D codes.

Unknown model ID

The Printer page can show that the printer reported a model ID that is not in the list. Then select the nearest model in Settings and try each command set in the print dialog. Open an issue with the model ID so that the model can be added.

AI assistant cannot connect

  • Make sure that Allow AI assistants to use OwnYourNiimbot is on and that the app is open.
  • After an app update, reconnect the assistant. In Claude Code, run /mcp.
  • If you made a new token, update it in the assistant.
