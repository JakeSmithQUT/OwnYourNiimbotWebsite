The design view is where you make a label. It has the Insert panel on the left, the toolbar and the label in the middle, and the settings of the label or the selected element on the right.

Label settings

When no element is selected, the right panel shows the settings of the label:

  • NIIMBOT roll: the rolls for the printer model. Select a roll to set the width, the height and the label type.
  • Width and Height: the label size in millimetres.
  • Label type: gap (die-cut), black mark, continuous, transparent and the other types that the model supports.
  • Corner radius (preview only): the rounded corners of the label in the editor. It does not change the print.
  • Snap grid: the step for moving and resizing.

If the roll in the printer has a different size from the label, a banner above the label offers Use W × H mm and Keep this size.

Element settings

Select an element to show its settings. Each element has a Position section with X, Y, width and height in millimetres, and rotation in steps of 90°. Select more than one element to align them with the toolbar.

Status bar

The bar under the label shows the printer model, its resolution and the width of the print head, for example "B1 · 203 dpi · print head 48 mm". On some models the label prints sideways, and the editor shows "Printed sideways on this model" under the label.

Mouse and keyboard

  • Right-click an element for the element menu.
  • Hold Ctrl and scroll to zoom.
  • Arrow keys move the selected elements by 0.5 mm. Hold Shift to move by 5 mm.
