--- title: Privacy and the data folder description: OwnYourNiimbot has no account, no analytics and no cloud service. Where it stores labels and settings on Windows, macOS and Linux, and how to back them up. section: App and settings order: 5 ---

The app has no account, no analytics and no cloud service. Labels, print history and settings stay on your computer.

Internet connections

The update check is the only internet connection of the app. It asks GitHub for the latest release, and GitHub gets the app version and the IP address of the computer. The app sends no labels or other data. To turn the check off, go to Settings, Updates.

The MCP server for AI assistants is off by default. When you turn it on, it accepts connections from this computer only.

Data folder

Click Settings, Open data folder to open it. The folder is in these places:

SystemFolder
Windows%APPDATA%\OwnYourNiimbot
macOS~/Library/Application Support/OwnYourNiimbot
Linux~/.config/OwnYourNiimbot

The folder holds your saved labels, the print history, the settings, the sizes that you saved for rolls, the update settings and the MCP token.

Back up and move labels

  • To back up everything, close the app and copy the data folder.
  • To move everything to another computer, close the app on both computers and copy the folder to the same place on the other computer.
  • To share one label, export it as a label file from the Labels page. See Saved labels and label files.

Bluetooth and USB

The app connects only to the printer that you select. It asks before it pairs with a Bluetooth device, and NIIMBOT printers do not need pairing.

Open source

The source code is public under the MIT licence, so anyone can check what the app does. The repository contains no code, images, fonts, templates or translations from the official NIIMBOT app.
