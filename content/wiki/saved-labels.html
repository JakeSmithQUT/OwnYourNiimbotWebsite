--- title: Saved labels and label files description: Save, open, duplicate, export and import labels in OwnYourNiimbot. Label files are JSON files that you can share or keep as a backup. section: Design labels order: 9 ---

The Labels page shows the labels that you saved. Labels are saved on this computer only.

Save a label

Press Ctrl + S or click Save at the top of the window. The name at the top left is the label name. Click it to change it. "Not saved" next to the name means that the label has changes that are not saved.

To keep a saved label and make a new label from it, change the name and save. The app saves a new label and keeps the old one.

Open a saved label

On the Labels page, click a label to open it in the design view. If the current label has changes that are not saved, the app asks before it closes it.

Label actions

ButtonAction
New labelOpens the New label dialog. Select a NIIMBOT roll or enter the width and height, then click Create
ImportOpens a label file (.json) and adds it to your labels
DuplicateMakes a copy of the label with " copy" after the name
ExportSaves the label as a label file (.json)
DeleteDeletes the label. You cannot undo this

Label files

A label file is a JSON file that holds the label size, the elements and the embedded images. Use it to send a label to someone else, to move labels to another computer, or as a backup.

The app checks every label file before it opens it. It does not open a file that is larger than 50 MB, that links to images on other computers or websites, or that has elements that are not valid. The message tells you the reason.

Data saved with a label

When a spreadsheet is loaded on the Data page, the label keeps the data when you save it, up to 5,000 rows. The label opens with its data next time.

Back up all labels

Labels, print history and settings are in the app data folder. To back up everything, close the app and copy the folder. See Privacy and the data folder.
