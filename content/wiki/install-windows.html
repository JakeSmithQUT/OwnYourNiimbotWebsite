--- title: Install on Windows description: Install OwnYourNiimbot on Windows 10 or 11, get past the SmartScreen warning, use the portable version, and remove the app. section: Install and set up order: 1 ---

OwnYourNiimbot runs on Windows 10 and 11, on Intel, AMD and Arm processors. The installer has no questions and installs the app for your user only, so it does not need administrator rights.

Install the app

  1. Download the installer: {%file windows-x64%} ({%size windows-x64%}). For a Windows on Arm computer, download the Arm64 installer.
  2. Open the file. If SmartScreen shows "Windows protected your PC", click More info, then Run anyway.
  3. The installer adds a desktop shortcut and a Start menu shortcut, then opens the app.

Windows shows the SmartScreen warning because the app is not code signed. Download the app only from this site or from the GitHub releases page. To check the file, compare its SHA-256 checksum with the value on the download page:

Get-FileHash .\{%file windows-x64%} -Algorithm SHA256

Portable version

The portable version, {%file windows-portable%}, runs without installation. Put it in a folder and open it. It does not install updates itself: when a new version is available, it shows a link to the release page.

The portable version runs from a temporary folder, so Claude Desktop cannot start its MCP bridge. To use Claude Desktop with the app, use the installer.

Updates

The installed app checks for a new version when it starts and every 6 hours. It downloads the update and installs it when the app restarts. See Updates.

Remove the app

Open Settings, Apps, Installed apps in Windows, find OwnYourNiimbot and click Uninstall. Labels and settings are in the app data folder, %APPDATA%\OwnYourNiimbot. Delete that folder too if you do not want to keep them.
