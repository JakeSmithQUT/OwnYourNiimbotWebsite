--- title: Install on Linux description: Install OwnYourNiimbot on Linux with the AppImage or the .deb package, set up Bluetooth with BlueZ, and give your user access to USB serial ports. section: Install and set up order: 3 ---

OwnYourNiimbot for Linux comes as an AppImage, which runs on most distributions, and as a .deb package for Debian, Ubuntu and similar systems. Both are available for x64 and Arm64.

AppImage

  1. Download the AppImage: x64 ({%size linux-x64-appimage%}) or Arm64.
  2. Make the file executable and start it:
chmod +x ~/Downloads/OwnYourNiimbot-*.AppImage
~/Downloads/OwnYourNiimbot-*.AppImage

The AppImage installs updates itself. If it reports that FUSE is missing, install the libfuse2 package (libfuse2t64 on Ubuntu 24.04 and later).

Debian and Ubuntu package

Download the x64 package or the Arm64 package, then install it with apt:

sudo apt install ./{%file linux-x64-deb%}

The .deb package does not install updates itself. When a new version is available, the app shows a link to the release page.

Bluetooth

Bluetooth needs BlueZ 5.41 or later. Most current distributions have a newer version. Make sure that Bluetooth is on in the system settings. You do not need to pair the printer.

USB cable

To use a USB cable, your user needs access to serial ports. Add your user to the dialout group, then log out and log in again:

sudo usermod -aG dialout $USER

On Arch Linux and related systems the group is uucp:

sudo usermod -aG uucp $USER

Check the download

Compare the checksum with the value on the download page:

sha256sum ~/Downloads/{%file linux-x64-appimage%}

Data folder

Labels and settings are in ~/.config/OwnYourNiimbot.
