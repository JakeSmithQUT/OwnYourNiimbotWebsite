--- title: Data fields description: Reference for OwnYourNiimbot data fields: spreadsheet columns, the date, the time, the label number with leading zeros and custom date formats. section: Data and batch printing order: 2 ---

A data field is a name in double braces, for example {{Name}}. When the label prints, the app replaces the field with a value. Fields work in text, barcodes, QR codes and table cells.

Spreadsheet columns

A field with the name of a column gets the value of that column for each row. The name does not depend on upper and lower case, so {{name}} and {{Name}} are the same. Load the data on the Data page. See Batch printing.

When data is loaded and a field has no matching column, the field prints as an empty value. When no data is loaded, the field prints as it is written.

Built-in fields

FieldValueExample
{{date}}The date when the label prints, DD/MM/YYYY22/11/2026
{{time}}The time when the label prints, HH:mm14:05
{{datetime}}Date and time, DD/MM/YYYY HH:mm22/11/2026 14:05
{{index}}The number of the label in the print job, from 17
{{index:4}}The label number with leading zeros to the given number of digits0007
{{date:FORMAT}}The date in your own format{{date:D MMM YYYY}} gives 22 Nov 2026

A column with the same name as a built-in field takes priority. For example, a column called Date replaces {{date}}.
