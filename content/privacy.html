This page is about the website. For the app, see Privacy and the data folder.

Cookies, analytics and tracking

  • It sets no cookies and stores nothing in your browser.
  • It has no analytics, no advertising and no tracking scripts.
  • It loads no fonts, scripts or images from other sites.

Hosting

Cloudflare hosts the website. Like every web server, Cloudflare receives your IP address and the pages that your browser asks for, and it can keep these in its logs. The Cloudflare privacy policy applies to that data.

Downloads

The download buttons get the files from the GitHub release of the app. When you download a file, GitHub receives your IP address and the name of the file. The GitHub privacy statement applies to that data.

Wiki search

The wiki search runs in your browser. It downloads a list of the wiki pages from this site and sends nothing to a server.

Contact

Open an issue on GitHub for questions about this website. Report a security problem through a private security advisory.
