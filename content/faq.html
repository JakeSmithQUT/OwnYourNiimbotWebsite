Common questions about OwnYourNiimbot and about NIIMBOT label printers on a computer. The wiki has the full instructions.

Is there NIIMBOT label software for Windows?

Yes. OwnYourNiimbot is a free label designer for NIIMBOT printers that runs on Windows 10 and 11, on x64 and Arm processors. It connects to the printer over Bluetooth or a USB cable. Download it for Windows.

Can I use a NIIMBOT printer with a Mac?

Yes. OwnYourNiimbot has macOS versions for Apple silicon and Intel Macs. Allow Bluetooth access when macOS asks for it. Install on macOS tells you how to open an app that is not code signed.

Does it work on Linux?

Yes. There is an AppImage and a .deb package for x64 and Arm64. Bluetooth needs BlueZ 5.41 or later. For a USB cable, add your user to the dialout group. See Install on Linux.

Which NIIMBOT printers does it support?

{%printer-count%} models that use the NIIMBOT command set, including the D11, D110, D101, H1S, B1, B18, B21, B3S, B31, K3, M2 and M3 series. The supported printers page lists each model with its resolution, print width and label types. {%other-count%} models in the official app list, for example the B3, use a command set from a different manufacturer and do not work.

Do I need a NIIMBOT account or the phone app?

No. OwnYourNiimbot has no account and no sign-in, and it does not use the NIIMBOT cloud. Close the phone app before you connect, because the printer accepts one connection at a time.

Is OwnYourNiimbot made by NIIMBOT?

No. OwnYourNiimbot is an independent open-source project. NIIMBOT did not make, approve or support it. It contains no code, images, fonts, templates or translations from the official app.

Is it free?

Yes. The app is free, has no advertising and no subscription, and its source code is on GitHub under the MIT licence.

Do I need to install a printer driver?

No. The app talks to the printer directly over Bluetooth or a serial port. The printer does not show as a system printer, so other programs cannot print to it through OwnYourNiimbot. To print a design from another program, save it as an image and insert the image on a label.

Do I need to pair the printer in the Bluetooth settings?

No. Turn on the printer, click Connect printer in the app and select the printer. If Windows or macOS asks to pair, the printer does not need it. See Connect a printer.

Can I print labels from Excel or a CSV file?

Yes. Open an .xlsx, .csv or .tsv file on the Data page, or paste a table. Put columns on the label as fields, for example {{Name}}, and the app prints one label for each row. See Batch printing from a spreadsheet.

Does it work with rolls that are not genuine NIIMBOT rolls?

The app prints on any roll that the printer accepts. If the app cannot read the roll size, select the size in the NIIMBOT roll list or enter the width and height, then save the size for that roll. The number of labels left shows only for genuine rolls with an RFID tag.

Why does Windows say that it protected my PC?

The app is not code signed, so Windows SmartScreen shows "Windows protected your PC" the first time. Click More info, then Run anyway. Download the app only from this site or from the GitHub releases page, and compare the SHA-256 checksum if you want to check the file.

Does the app send my labels anywhere?

No. The app has no analytics and no cloud service. Its only internet connection is the update check, which asks GitHub for the latest release. You can turn the check off in Settings. See Privacy and the data folder.

How do I update the app?

The installed app checks for a new version when it starts and every 6 hours. On Windows and with the Linux AppImage, it downloads and installs the update. On macOS, with the portable Windows app and with the .deb package, it shows a link to the new release. See Updates.

Can an AI assistant make labels with it?

Yes. Turn on the local MCP server in Settings, AI assistants (MCP). An assistant such as Claude can then make labels, preview them and print them. By default the app asks you before an assistant prints. See AI assistants (MCP).

Which languages does the app have?

22: English, Bulgarian, Chinese (Simplified and Traditional), Croatian, Czech, French, German, Hindi, Hungarian, Italian, Japanese, Korean, Marathi, Polish, Portuguese (Brazil), Russian, Spanish, Swedish, Turkish, Ukrainian and Vietnamese. Templates and symbol names stay in English.

Is it for Nimmbot or Niimbot printers?

NIIMBOT is the brand name, and people also spell it Niimbot or Nimmbot. OwnYourNiimbot works with the NIIMBOT label printers in the supported printers list.

Where do I report a problem or ask for a feature?

Open an issue on GitHub. If a printer does not print correctly, add the model name, the firmware version and the communication log from the Printer page.
