OwnYourNiimbot works with {%printer-count%} NIIMBOT models that use the NIIMBOT command set. When a printer connects, the app reads its model ID and selects the command set, the resolution and the print width.

Printer pages

These pages show the label sizes and the setup steps for the most common models.

{%printer-links%}

Models with the NIIMBOT command set

The last column shows the command set that the app selects. To use a different command set, change Settings, Command set, or open Advanced in the print dialog. Leave it on Auto unless a printer does not print with the automatic choice.

{%printers-table%}

Models with a different command set

The official app lists these models, but they use a command set from a different manufacturer. OwnYourNiimbot does not support them. The B3 is a different printer from the B3S.

Hardware test status

The print commands are tested against a simulated printer in the app's test suite. If you print with a model, open an issue on GitHub with the model name, the firmware version and the result. If the print fails, attach the communication log from the Printer page.

If the printer reports a model ID that is not in the list, the Printer page shows the ID. Select the nearest model in Settings and try each command set in the print dialog.
