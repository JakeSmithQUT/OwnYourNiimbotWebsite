Free label designer for NIIMBOT printers

OwnYourNiimbot designs and prints labels on NIIMBOT label printers from Windows, macOS and Linux. It connects to the printer over Bluetooth or a USB cable. You need no account, no cloud service and no internet connection.

Features

Design a label with a mouse and keyboard, check the exact preview and print it. The app works with the NIIMBOT rolls that you already have.

  • {%icon type%}

    Label editor

    Text, barcodes, QR codes, Data Matrix, PDF417, Aztec, images, shapes, lines, tables and 571 symbols. Right-click an element to change its type.

  • {%icon layout-template%}

    Template library

    529 ready-made designs for IT, cables, the kitchen, retail, shipping, the workshop, school and events. The list shows the sizes that fit your printer and roll.

  • {%icon file-spreadsheet%}

    Batch printing

    One label for each row of an Excel, CSV or TSV file, or of a table that you copy from a spreadsheet.

  • {%icon hash%}

    Serial numbers and dates

    Numbers that count up on each label, and best-before or expiry dates that the app calculates when it prints.

  • {%icon ruler%}

    Automatic label size

    The app reads the roll in the printer and gives a new label the same size.

  • {%icon eye%}

    Print area and exact preview

    The editor shades the parts of the label that the print head cannot reach. The preview shows the dots that the printer receives.

  • {%icon image%}

    Photos and logos

    Dithering, threshold, brightness and contrast settings convert an image to black and white for a thermal printer.

  • {%icon printer%}

    Printer status and settings

    Battery level, the loaded roll, labels left on genuine rolls, the power-off time, sounds and label position calibration.

  • {%icon bluetooth%}

    Bluetooth or USB

    The app talks to the printer directly. You do not pair it in the system settings and you do not install a driver.

  • {%icon languages%}

    22 languages

    The app starts in the language of your system. Change it at any time with the globe button.

  • {%icon bot%}

    AI assistants

    An optional local MCP server lets an assistant such as Claude make, preview and print labels. It is off by default.

  • {%icon refresh-cw%}

    Automatic updates

    The installed app checks GitHub for a new version and installs it on Windows and Linux.

Template library with 529 designs

Start from a server label, a cable flag, a freezer label, a price tag, a shipping label or an asset tag. Each design comes in the sizes that suit it, and you change the text on the label.

  • Filter by the roll in the printer, the NIIMBOT rolls for your model, or every size
  • 17 categories, and decorative designs with 19 included fonts
  • Templates that count up or calculate a date, for asset tags and use-by labels

Batch printing from a spreadsheet

Print name badges, asset tags or server labels from a list. Open an Excel, CSV or TSV file, put the columns on the label as fields such as {{Name}}, then print a label for each row.

  • Fields in text, barcodes and QR codes
  • Print all rows or a range, with copies of each label
  • The data is saved with the label, up to 5,000 rows

Labels stay on your computer

The app has no account, no analytics and no cloud service. The update check is its only internet connection: it asks GitHub for the latest release. Labels, print history and settings stay in the app data folder.

The source code is on GitHub under the MIT licence. You can read it, build the app yourself and change it.
